# 🐙 GitHub 키오스크

**터미널 없이, 버튼으로** 내 GitHub 저장소를 관리하는 작은 개인 도구입니다.
내 컴퓨터(`127.0.0.1`)에서만 열리며, 외부에 아무것도 공개하지 않습니다.

화면에서 할 수 있는 것:
- 📋 내 모든 Git 저장소의 상태(변경됨 · 안 올라감 · 최신)를 한눈에
- ⬆️ 변경된 것을 골라 **한 번 클릭으로 커밋·푸시** (진행 과정 실시간 표시)
- ✏️ 저장소 설명 편집 · 📦 보관(archive)/복구

---

## 시작하기 (한 번만)

### Mac
1. 이 폴더의 **`start.command`** 를 더블클릭합니다.
2. 처음이라면 안내에 따라 **GitHub 로그인**을 한 번 합니다(브라우저가 자동으로 열립니다).
3. 끝! 키오스크가 브라우저에 자동으로 열립니다.

> 더블클릭 시 "확인되지 않은 개발자" 경고가 뜨면: 파일을 **우클릭 → 열기 → 열기**.

### Windows
1. 이 폴더의 **`start.bat`** 를 더블클릭합니다.
2. 안내에 따라 **GitHub 로그인**을 한 번 합니다.
3. 키오스크가 브라우저에 열립니다.

이후로는 같은 파일을 더블클릭하기만 하면 바로 열립니다.

> 📡 **밖에서도 iPhone으로 내 Mac을 쓰고 싶다면** → [`mac-remote/`](mac-remote/README.md) 의 `원격연결-설치.command` 를 Mac에서 한 번 실행해 두세요.

## 필요한 것 (대부분 이미 있거나, 실행 파일이 안내합니다)

| 도구 | 용도 | 없으면 |
|---|---|---|
| **Python 3** | 키오스크 실행 | [python.org](https://www.python.org/downloads/) 에서 설치 |
| **git** | 저장소 관리 | Mac은 보통 내장 · Windows는 [git-scm.com](https://git-scm.com/download/win) |
| **GitHub CLI (gh)** | GitHub 연결 | [cli.github.com](https://cli.github.com) (Mac은 `brew install gh`) |
| **GitHub 계정** | 로그인 | [github.com/join](https://github.com/join) |

> **솔직히 말하면** — “완전 무설정”은 어떤 앱도 불가능합니다. 위 도구가 있어야 하고, GitHub에 **한 번은 로그인**해야 합니다(모든 앱의 ‘로그인’과 같습니다). 실행 파일이 이 과정을 자동으로 점검·안내하므로, 여러분이 고민할 단계는 사실상 **GitHub 로그인 한 번**뿐입니다.

## 자주 묻는 것

- **내 프로젝트가 안 보여요** → 화면 위 "📂 프로젝트 폴더"를 여러분이 코드를 두는 폴더(예: `~/Desktop`, `~/Documents`)로 바꿔 보세요. 기본값은 홈 폴더 전체 검색입니다.
- **"원격없음" 배지** → 아직 GitHub에 안 올라간 로컬 전용 저장소입니다. 먼저 GitHub에 저장소를 만들어 연결해야 푸시할 수 있습니다.
- **푸시가 거부돼요** → 대개 **100MB 넘는 파일** 때문입니다. 로그 메시지가 어떤 파일인지 알려줍니다 — 그 파일을 `.gitignore` 에 적으세요.
- **안전한가요?** → 이 도구는 삭제·강제푸시 같은 위험한 작업을 하지 않으며(보기·커밋·푸시·설명·보관만), 내 컴퓨터에서만 작동합니다.
