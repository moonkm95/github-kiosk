# 📡 Mac 원격 연결 — 밖에서도 Mac 앱처럼 내 Mac 쓰기

Mac 앞에서 **한 번만** 설치해 두면, 이후에는 iPhone의 Claude 앱이나 claude.ai/code 에서
내 Mac의 세션을 열어 **Mac 앱과 똑같이** 이 Mac의 파일·도구·로그인 정보로 작업할 수 있습니다.

## 설치 (Mac 앞에서, 한 번만)

1. 이 폴더의 **`원격연결-설치.command`** 를 더블클릭합니다.
   (경고가 뜨면 우클릭 → 열기 → 열기)
2. 안내에 따라 진행합니다.
   - Claude Code 설치·로그인 확인 (iPhone 앱과 **같은 계정**)
   - 밖에서 작업할 폴더 선택
   - 폴더 신뢰 확인 한 번 (`/exit` 로 닫기)
3. "✅ 원격 연결이 켜졌습니다" 가 보이면 끝.

이후에는 Mac을 켜고 로그인할 때마다 **자동으로** 시작되고, 꺼지면 **자동으로 다시** 켜집니다.

## 밖에서 쓰기

iPhone Claude 앱 → **Code** → 세션 목록에서 **Mac 이름**으로 된 세션을 엽니다.
명령과 파일 작업은 모두 Mac에서 실행되고, 앱은 화면만 보여 줍니다.

## 연결이 유지되려면 (중요)

Remote Control은 **Mac이 깨어 있고 인터넷에 연결된 동안만** 동작합니다.

| 항목 | 설정 |
|---|---|
| 전원 | 전원 어댑터 연결 (실행 중에는 잠자기를 자동으로 막음) |
| MacBook 덮개 | 닫으면 잠듭니다 (외부 모니터 연결 시 제외) |
| 시스템 설정 → 에너지 | "디스플레이가 꺼져 있을 때 자동으로 잠자기 방지" · "네트워크 접근 시 깨우기" 켜기 |
| 재부팅 대비 | 시스템 설정 → 사용자 및 그룹 → 자동 로그인 |

## 문제 해결

- 기록 보기: `~/Library/Logs/ClaudeRemote.log`
- `Operation not permitted` 가 보이면: 작업 폴더가 데스크탑·문서·다운로드 안에 있는 경우입니다.
  폴더를 `~/Developer` 등으로 옮기고 다시 설치하거나,
  시스템 설정 → 개인정보 보호 및 보안 → **전체 디스크 접근 권한**에 `/bin/bash` 를 추가하세요.
- 폴더를 바꾸려면: 설치 파일을 다시 실행하면 덮어씁니다.
- 끄려면: **`원격연결-해제.command`** 더블클릭.
